把纸质说明书拍下来，随时能查。

一个**完全离线**的 Android 应用：拍照归档纸质说明书 → 自动裁边拉正 → 文件夹 + 标签双轨组织 → 关键词搜索 → 导出 PDF / 整库备份。

**没有账号，没有云端，没有网络权限。** 数据只存在你自己的手机上。

## 功能

### 拍照归档

- **连续多页拍摄** —— 拍完一页接着拍下一页，一气呵成
- **自动裁边拉正** —— 识别纸张四角并做透视变换，拍歪了也能救回来
- **手动微调** —— 自动识别不准时，四个角点可以直接拖
- **自动压缩** —— 最长边 1600px / JPEG 质量 80，一张 3MB 的原图压到约 250KB
- **相册导入** —— 已有照片可直接导入，走同一条处理管线
- **导出 PDF** —— 多页合并成一份 A4 PDF

### 组织与检索

- **文件夹** —— 多级层级（家电 / 厨房 / 冰箱），长按可重命名、删除
- **标签** —— 一份设备可打多个标签，交叉筛选
- **关键词搜索** —— 匹配名称、品牌、型号、备注、标签

### 阅读

- 全屏阅读器，左右滑动翻页，双指缩放

### 数据安全

- **整库备份** —— 导出 `.zip`（数据 + 全部图片），换机一键迁移
- **备份还原** —— 支持「合并导入」与「覆盖导入」两种模式
- **存储统计与残留清理**

### 界面

**黑白灰**。说明书本身是花花绿绿的印刷品，界面越素，内容越突出。
Material 3 动态深浅色主题，标签靠灰阶深浅区分，无彩色干扰。

## 使用说明

### 1. 拍下第一份说明书

1. 打开 App，默认在「**资料库**」页
2. 点右下角 **+**，填个名字（比如「厨房净水器」），保存
3. 进入该设备详情页，点「**拍照**」
4. 对准说明书按快门 —— **尽量让纸张占满画面，四条边都进画面**
5. 拍完自动识别四角。**识别不准就拖动四个角点微调**，确认后进入下一页
6. 继续拍，全部拍完点「完成」

> 手里已有照片？在拍照页点左下角的相册按钮导入，会走同一套裁边流程。

### 2. 整理

- **文件夹**：资料库页可新建文件夹、把设备移进去；长按文件夹可重命名、删除
- **标签**：在设备编辑页给设备打标签；切到「**标签**」页可按标签交叉筛选
- **设备卡片**：长按出上下文菜单，可移动、编辑、删除

### 3. 查找

资料库页顶部搜索框，输入任意关键词即可 —— 会匹配**名称 / 品牌 / 型号 / 备注 / 标签**。

### 4. 阅读与导出

- 进设备详情页可看到所有页的缩略图，可拖动排序
- 点任意一页进入**全屏阅读器**：左右滑动翻页、双指缩放、单击显隐工具栏
- 详情页点「**导出 PDF**」把多页合并成一份 PDF

### 5. 备份与换机

1. **设置 → 备份与恢复 → 导出备份**，得到一个 zip（数据 + 全部图片）
2. 换到新手机：装 App → **设置 → 导入备份**
   - **合并导入** —— 保留新机上已有数据，把备份追加进来
   - **覆盖导入** —— 清空后完全用备份替换

### 6. 拍照小技巧

- 让纸张尽量占满画面，四条边都进画面
- 光线尽量均匀，避免「一半亮一半暗」的强阴影
- 深色封面、米色/泛黄纸张都能识别，不用特意换浅色背景

## 常见问题

**裁边不准怎么办？**
在裁剪页手动拖动四个角点就行 —— 那本来就是为这种情况准备的功能。

**能搜到说明书里的文字吗？**
不能。v1 不做 OCR，搜索范围限于你手填的名称 / 品牌 / 型号 / 备注 / 标签。

**换手机数据会丢吗？**
不会，但要你自己操作一次导出 / 导入。因为没有云端，所以没有自动同步。

**支持哪些手机？**
Android 8.0 及以上、`arm64-v8a` 架构（这个版本之后的手机基本都是）。

## 权限与隐私

只申请一个权限：`CAMERA`。

- 读取相册走系统 Photo Picker，**不需要任何存储权限**
- Manifest 里**没有** `INTERNET` 权限 —— 从权限层面证明这个应用不可能联网
- 数据全部存在本机私有目录，**卸载即清空**
